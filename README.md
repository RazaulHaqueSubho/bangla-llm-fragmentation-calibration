# Bangla LLM Calibration

This research project investigates the relationship between tokenization fragmentation and confidence calibration in Bangla Large Language Models (LLMs).

## Research Objectives
- Compare tokenization fragmentation in Bangla and English.
- Evaluate model accuracy and confidence calibration.
- Investigate whether fragmentation is associated with calibration errors.

## Metrics
- Tokens per Word (TPW)
- STRR (definition to be verified)
- Accuracy
- Brier Score
- Expected Calibration Error (ECE)
